# Para Irenica ♡

Micrositio móvil e interactivo creado como sorpresa de aniversario.

## Experiencia
- Carta animada con sobre y sello.
- Mensaje de aniversario.
- Revelación del regalo: Termas de Alange.
- Galería táctil con las fotos elegidas.
- Selector de fecha.
- Confirmación con cuenta atrás y corazones.
- Botón para compartir por WhatsApp la fecha elegida.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta manteniendo `assets/`.
3. En el repositorio ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)` y guarda.

La web no necesita build ni dependencias.
